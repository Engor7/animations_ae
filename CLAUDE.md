# Animations workspace

Цель: живые, аккуратные анимации плоских иллюстраций (PNG с прозрачностью) для интерфейсов сайтов.
Пользователь говорит по-русски, ценит **скорость и экономию токенов** — работай коротко, без лишних экспериментов.

## Как работать
- **Анимацию всегда делаем в After Effects** (мост, см. раздел After Effects): пользователь сам смотрит и правит проект.
  Питон/`animkit` — только вспомогательно: карты смещения, замеры, кодирование финального файла.
- Результат — **один готовый файл** всей композиции для сайта (как «гифка»/видео). Никаких слоёв по отдельности,
  раскадровок, превью-страниц и вариантов форматов.

## Где что лежит — одна папка на композицию
Пользователь даёт папку с исходниками (например `грибная анимация/`) — **всё по этой композиции живёт только в ней**:
```
<папка>/
  <имя>.aep                 проект AE (правки — здесь)
  <имя> анимация.webp       готовый файл для сайта
  исходники/                файлы пользователя, как дал
  служебное (не трогать)/   карты смещения и прочее, на что ссылается проект
```
- Никаких `projects/`, копий исходников, скриптов и кадров в других местах. Промежуточное (кадры рендера и т.п.) — только
  во временной папке сессии, после работы удалить. Папку `<имя>.aep Logs`, которую создаёт aerender, удалять.

## Требования к результату (по умолчанию)
- Формат: анимированный **WebP** с прозрачностью, ширина ~640 px (вес ≲ 10 МБ). Вставляется как `<img>`.
  Другое — только по запросу (MP4 на фоне сайта, WebM+MOV, APNG, GIF).
- Края гладкие (8-бит альфа), бесшовный цикл: конец = начало, периоды делят длину цикла.

## Экономия времени и токенов
- Один формат, без сравнений кодеков, если не просили.
- Визуальная проверка: 1 контакт-лист (`animkit sheet`) на итерацию; координаты — через `animkit grid` + OpenCV, не перебором пикселей.
- Кодировщики сами проверяют результат (длительность, альфа по кадрам) — не перепроверяй вручную.
- Playwright MCP — только когда нужно увидеть реальное воспроизведение в браузере (`animkit html` + `python3 -m http.server`).
- Промежуточные отчёты — одной строкой.

## Команды
```
.venv/bin/python -m animkit sheet  <frames> <out.png> [--times 0,1200] [--crop x0,y0,x1,y1]
.venv/bin/python -m animkit grid   <image> <out.png> --box x0,y0,x1,y1 --step 25 --zoom 2
.venv/bin/python -m animkit encode <frames> --apng a.png [--webp a.webp --webm a.webm --mov a.mov --mp4 a.mp4 --bg '#fff' --gif a.gif] [--width 1086]
.venv/bin/python -m animkit html   <out.html> <files...>
```

## After Effects
- Управление AE — через мост: MCP-сервер `after-effects` (`ae_eval`, `ae_state`, `ae_frame`), панель
  Claude Bridge открывается в AE сама. Код и грабли: `tools/ae-bridge/README.md`.
  Если MCP-инструменты не подгружены — тот же мост из питона: `sys.path.insert(0, "tools/ae-bridge"); import mcp_ae; mcp_ae.bridge("/eval", {"code": ...})`.
- Запасной путь, если панель закрыта: `osascript -e 'tell application "Adobe After Effects 2026" to DoScriptFile "…"'`
  (результат не возвращается — писать лог в файл).
- Схема AE-проекта: питон печёт 16-бит карты смещения в `служебное (не трогать)/`, JSX через мост собирает риг
  (Displacement Map с выражениями, частицы — shape-слои с выражениями от `time % цикл`, все ползунки на слое CONTROLS).
- Рендер финала: `aerender -project <папка>/<имя>.aep -rqindex 1 -OMtemplate "TIFF Sequence with Alpha" -output <tmp>/f_[####].tif`
  (8 бит, straight alpha) → `animkit.encode.webp(..., width=640, quality=82)` прямо в папку композиции.
